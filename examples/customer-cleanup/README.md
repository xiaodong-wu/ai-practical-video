# 合成客户表整理示例

所有公司与邮箱都是虚构示例，`.example` 域名不会指向真实客户。

```sh
python3.12 examples/customer-cleanup/clean.py
```

默认输出到本目录的 `output/`。预期：输入 8 条、按邮箱删除重复 2 条、保留 6 条、缺少邮箱待复核 2 条。相同公司下的不同邮箱保留；没有邮箱时不猜地址、不自动删除。

`prompt.txt` 是可交给 AI 的任务说明；`clean.py` 是确定性演示程序。运行它可以核对输出，不代表完成视频生产或证明任何第三方 AI 界面的行为。将此案例拍成视频时，仍需由技能记录当前操作与真实输出。

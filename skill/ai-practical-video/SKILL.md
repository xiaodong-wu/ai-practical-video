# AI 实操视频

把一个可验证业务结果讲清楚：真实操作为主体、局部放大与步骤标注、少量说明动画。搜索、实测、写稿、配音、预览、验收均由当前 Codex 会话推进，不逐站等待用户确认。脚本不是独立联网大模型服务：联网研究与写作使用当前会话已有工具和账号，制作助手处理本地确定性步骤。

## 入口与准备

- “搜索最新 AI 热点，制作今天的一条视频”：执行自动选题。
- “把 AI 整理客户名单做成一条视频”：直接围绕指定用途实测，仍核验功能和费用。
- “继续上次任务”：查当前制作目录的 `runs/*/manifest.json`，先 `status`，从最早缺失、失败或过期步骤继续，不新建重复任务。多个等待任务无法辨明时才询问任务编号。

第一次读取 [运行与数据格式](references/workflow.md)。技能路径用当前 SKILL.md 所在目录；项目默认当前工作目录下 `ai-practical-video-project`。每次 `pipeline.py init` 创建独立 run。读取 `scripts/local.json` 的 Python、Playwright、免费声线配置；缺依赖按 [本地运行配置](references/runtime.md) 准备。单任务顺序执行，制作命令有文件锁。不要把旧样片的结果当新实测。

## 选题与真实性

先读 [热点与选题](references/research.md)。默认最近 7 天，优先 72 小时，保存北京时间搜索时间、事件发生时间、来源发布时间和核验链接。最多 10 候选，主张功能必须有官方来源及实际验证。近期消息不自动等于热门：使用 `pipeline.py select` 分类评分，保存原始来源和未选原因。30 天按工具、功能、场景去重；重要更新需具体变化和来源。无可做热点才回退常青案例并说明原因。

先用模拟或脱敏数据完成业务操作，再写最终稿。保存原始输入、提示词、执行脚本、实际输出、结果检查和录屏。浏览器必须真实交互；本地文件可用自建预览器显示，持续标明“本地文件预览”。不得重绘第三方软件界面冒充操作。发现隐私信息先遮罩再录制，原始秘密不进交付。无登录/权限的候选换题；实操失败允许修复一次，再选下一可执行题。不得自行购买订阅、开付费 API 或用真实客户数据。

## 写稿与制作

读 [写稿与画面交接](references/scriptwriting.md)。结构固定为结果预览 → 工作问题 → 2—3 个关键操作 → 结果核对 → 一句相关服务。内部写 3 种不同开头并选择。每句旁白绑定实测证据，费用/账号/访问条件写入发布文案；不能编造节省时长、收入或一键完成全部工作的效果。

默认免费女声为 **Kokoro v1.1-zh 的 zf_001**，配置文件保存完整声线与模型校验值。用户指定声线时遵从本次任务要求。相同文本、模型、声线、合成参数复用缓存；不自动切音色。新增付费声音或生成能力必须先给用途、币种、预计金额、计费范围，获得明确确认后才调用。免费本地配音可直接执行。

按实测音频安排镜头和字幕，超出 60—90 秒则修改脚本重配；不得通过加速或截断凑时长。`voice.py` 本地生成分句音频与时间；`produce.py timeline` 创建时间线与 SRT；`capture.mjs` 录制实际浏览器动作。现有登录页应优先使用已授权浏览器能力，不复制个人浏览器配置或绕过登录。

默认 1080×1920、30fps、H.264/AAC，背景音乐关闭。预览阶段用 540×960。检查每个镜头、最长字幕、360×640 手机图和旁白完整性；保守预留顶部120、底部160、右侧132像素，关键内容避开遮挡。平台 UI 会变化，这些是制作默认留白，不是平台官方安全区保证。

## 验收、恢复与交付

先 `produce.py preview`，运行 `audit-layout.mjs`，实际查看预览/关键帧并做音频检查，填写带当前预览 SHA 的 `qa/preview-review.json`。不能仅为了通过门禁把布尔值改为 true。若只能做 ASR/信号检测，写明方式与局限，不声称人工听审。预览通过才执行 `final`、`qa`、`package`。

每步成功用 `pipeline.py seal` 登记实际输入输出哈希，失败用 `fail`，等待登录或费用确认用 `wait`。技术失败最多自动修复两次；达到上限保留现场、说明原因。脚本改动后 `status` 自动使配音、字幕、预览、成片和包失效。已完成阶段保持可复用；当前不支持跨机器账号自动恢复。

交付 MP4、两平台独立封面/标题/简介/话题、SRT、旁白/分镜、演示文件、来源/许可、AI声明建议、QA报告、手机联系表、编辑源码与 ZIP。平台文案包含有依据的使用前提及相关服务方向。只有 QA 和素材包都通过，才写“成片已完成，待手动上传”，状态为 `completed_local`；永远不写“已发布”。

工具改编与固定版本见 [来源说明](references/provenance.md)。新脚本不要从上游整份 SKILL 引入财经人物舞台或逐站确认流程。
